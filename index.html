산정 근거

홈택스 연동 스크래핑 API — 제안 및 선정 이유

1안: 하이픈(Hyphen) / 2안: 쿠콘(Coocon) 이중 구성을 제안합니다. 두 벤더 모두 국세청 홈택스 자료 조회와 민간 간편인증(카카오·PASS 등)을 지원하나, 아래와 같은 이유로 하이픈을 1안으로 제안합니다.

  • 하이픈(1안) — 홈택스·위택스 등 국세/지방세 조회에 특화되어 신고·납부·환급·고지내역 항목 커버리지가 넓고, 간편인증 채널이 다양합니다. REST/JSON 기반의 개발 친화적 규격과 샌드박스 제공으로 착수 초기 PoC 속도가 빠르며, 건별 단가가 상대적으로 경쟁력이 있습니다.
  • 쿠콘(2안) — 국내 최대 규모의 스크래핑·마이데이터 사업자로 금융권 레퍼런스와 SLA가 강점입니다. 대량 트래픽 및 장기 안정성 측면에서 우위가 있어, 하이픈 장애 시 페일오버 백업 채널로 병행 계약하는 구성을 권장합니다.
  • 벤더 종속 제거 — 스크래핑 연동부를 Provider 인터페이스로 추상화하여 설정 전환만으로 벤더를 교체할 수 있도록 개발합니다. 추후 단가 재협상이나 벤더 변경 시 추가 개발 비용이 발생하지 않습니다.
  • 최종 선정 절차 — 착수 후 4주 내 두 벤더 샌드박스 PoC를 수행하여 항목 커버리지·평균 응답속도·실패율·건별 단가를 비교표로 제출하고, 클라이언트께서 최종 확정하시는 방식을 제안드립니다.

PRD (Product Requirements Document)

프로젝트 요구사항을 정의하고 기능 범위를 명확히 합니다.

1. 프로젝트 배경 및 목적

세무법인 고객이 간편인증 한 번으로 홈택스 자료를 불러오고, 예상 세액 및 환급액을 즉시 확인한 뒤, 세무대행 수수료 결제 또는 상담 신청까지 이어지는 반응형 웹 플랫폼을 신규 구축합니다.

  • 고객 관점 — 세무서 방문이나 서류 제출 없이, 카카오 간편인증만으로 본인의 예상 세액·환급액을 확인하고 즉시 세무대행을 신청할 수 있습니다.
  • 세무법인 관점 — 고객 데이터 수집·세액 산출·결제·상담 배정까지의 수작업 과정을 자동화하여 담당자 1인당 처리 가능 고객 수를 확대하고, 마케팅 동의 고객 풀을 자산화합니다.
  • 사업 목표 — 2027년 1~2월 런칭을 목표로, 종합소득세·부가가치세·법인세 3종 자동계산 엔진과 통합 관리자 백오피스를 90일 내 상용 배포합니다.

3.1 회원가입 및 인증 시스템

  • [필수] 카카오싱크 기반 회원가입 및 로그인 (동의항목 자동 수집)
  • [필수] 신규 고객 / 기존 고객 DB 매핑 및 구분 처리 (성명·연락처·사업자번호 기준 매칭 룰 정의)
  • [필수] 이용약관 · 개인정보 수집이용 동의 (필수) / 마케팅 수신 동의 (선택) 데이터 개별 저장 및 이력 관리
  • [필수] 세무법인 카카오톡 채널 추가 여부 확인 API 연동 및 미추가 고객 대상 추가 유도 동선
  • [필수] 로그인 세션 관리, 자동 로그아웃, 중복 로그인 제어

3.2 홈택스 스크래핑 연동

  • [필수] 카카오 등 민간 간편인증 기반 홈택스 스크래핑 API 연동 (1안 하이픈 / 2안 쿠콘, Provider 추상화로 교체 가능)
  • [필수] 개인 · 개인사업자 · 법인사업자 유형별 신고내역 / 납부내역 / 환급내역 / 고지내역 데이터 파싱 및 정규화 저장
  • [필수] 인증 진행 상태 실시간 표시 (인증 요청 → 인증 완료 → 자료 수집 중 → 계산 중 → 완료)
  • [필수] 타임아웃 · 인증 실패 · 자료 없음 등 오류 유형별 사용자 안내 문구 및 재시도 로직 (지수 백오프, 최대 3회)
  • [필수] 스크래핑 원본 응답 로그 저장 (장애 원인 추적 및 파싱 오류 재처리용)
  • [선택] 벤더 장애 감지 시 2안 벤더로 자동 페일오버

3.3 세액 계산 엔진 (3대 세목)

  • [필수] 종합소득세 예상 납부세액 및 환급액 자동 계산
  • [필수] 부가가치세 예상 납부세액 자동 계산 (일반과세자 / 간이과세자 구분)
  • [필수] 법인세 예상 납부세액 자동 계산
  • [필수] 계산 불가 · 예외 케이스의 '세무사 추가 검토 대상' 플래그 처리 및 사유 코드 기록
  • [필수] 과세연도별 세율 · 과세표준 구간 · 공제 한도 파라미터 테이블 관리 (관리자 화면에서 등록·복제)
  • [필수] 산출 근거 표시 (반영된 자료 목록, 적용 세율, 공제 항목, 기납부세액)
  • [필수] 결과 화면 및 약관에 '예상치이며 확정 신고 자료가 아님' 고지 문구 노출

세목별 자동계산 구현 가능 범위 및 한계점

세목자동계산 가능 범위한계점 (세무사 검토 플래그 처리)

정확도 상		 전자세금계산서·신용카드·현금영수증 매출/매입 자료 기반 일반과세자 예상 납부세액, 간이과세자 업종별 부가가치율 적용 예상세액, 단순 의제매입세액, 예정고지·기납부세액 반영 매입세액 불공제 항목 자동 판정(접대비, 비영업용 승용차 등 → 사용자 확인 입력 필요), 수출 영세율 및 재화 수입분, 대손세액 공제·가산, 겸영사업자 공통매입세액 안분
법인세
정확도 중 — 범위 제시형 권장		 홈택스 조회 전기 신고서 기반 추정, 당기순이익 및 주요 세무조정 항목 직접 입력 기반 각사업연도소득 추계, 과세표준 구간별 세율 적용, 기납부세액(중간예납·원천징수) 반영 익금산입·손금불산입 등 60여 종 세무조정 자동화 불가 (재무제표·장부 연동 없이는 구조적 한계), 이월결손금 공제, 각종 공제·감면 및 최저한세, 연결납세·조합과세 → 단일 금액이 아닌 예상 구간(range) 제시 + 세무사 검토 필수 안내 방식을 권장

무엇보다 동일 규모의 B2B 플랫폼을 9주(약 63일) 만에 상용 배포한 실적이 있어, 본 프로젝트의 90일 일정과 12주차 배포 마일스톤을 안정적으로 준수할 수 있습니다. 고객 목록·상세·대시보드·엑셀 다운로드 등 백오피스 반복 구조는 검증된 설계를 재활용하여 리스크를 줄입니다.

프로젝트 개요

주간보호센터의 케어 기록·투약 관리·보호자 커뮤니케이션을 통합한 멀티테넌트 B2B SaaS입니다. 건강 관련 민감정보를 다루며 기관별 데이터 격리와 알림 자동 발송 체계를 구축했습니다.

핵심 기능

  • 멀티테넌트 아키텍처 및 기관별 데이터 격리·권한 통제
  • 건강 민감정보 암호화 저장 및 접근 권한별 마스킹 처리
  • 보호자 대상 단계별 자동 알림 발송 (상태 변경 트리거 기반)
  • 전자서명 및 동의서 처리, 이력 관리
  • AI 기반 건강 분석 리포트 자동 생성
  • 133K+ LOC, 140+ API 엔드포인트, 6 플랫폼 지원

본 프로젝트와의 유사점

민감정보 취급과 단계별 자동 알림 체계 경험이 본 프로젝트와 맞닿아 있습니다. 건강정보라는 민감정보를 권한별 마스킹·암호화로 통제한 경험은 주민등록번호 양방향 암호화 및 관리자 조회 로그 요구사항에 직접 적용됩니다.

또한 '상태 변경 → 자동 알림 발송' 트리거 구조는 본 프로젝트의 솔라피 단계별 알림톡 자동 발송(인증 완료 / 계산 완료 / 결제 완료 / 검토 대상 안내) 설계와 동일한 패턴이며, 동의서 처리 및 이력 관리는 이용약관·개인정보·마케팅 수신 동의 데이터 처리 요구사항에 대응됩니다.
